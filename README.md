# ML Assignment 2

This project is part of the Machine Learning Assignment 2 for the Work Integrated Learning Programmes Division. It involves implementing multiple classification models, building an interactive Streamlit web application, and deploying it on Streamlit Community Cloud.

## Project Structure

- `streamlit_app.py`: The Streamlit app code.
- `requirements.txt`: List of dependencies.
- `model/`: Directory for saving model files.
- `test_data.csv`: Placeholder for the test dataset.

## Steps to Run the Project

1. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the Streamlit app:
   ```bash
   streamlit run streamlit_app.py
   ```

3. Access the app in your browser at `http://localhost:8501`.

## Deployment

The app will be deployed on Streamlit Community Cloud. The deployment link will be shared upon completion.
